# Candidate evidence

本目录保存由历史 raw/summary 展开的逐 metric 候选证据，共 1,082 行，按六组图拆分。每行都保留来源、协议、可绘图等级、`REUSE/FIX/RERUN` 判定和 caveat。

这些 TSV 用于核对旧证据、设计正式 runner 和映射新数据字段；它们不是正式 figure-ready 输入。只有满足 `plan/FIGURE-DATA-REQUIREMENTS.tsv` 中 provenance、correctness、matched protocol 和独立重复门槛的数据，才能交给 `figures/scripts/formal/`。
